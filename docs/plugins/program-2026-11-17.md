# Plugin system completion program, 2026-11-17

The owner asked for a complete plugin system across EffectCraft, PhotoCraft and FigCraft. It covers
making, distributing, installing, managing and using plugins, with safety. It builds on PhotoCraft's
move onto the shared craft UI framework (photocraft `ed14e1c`, craft-libs `a6b9d9c`).

Inputs: [gap audit](research/gap-audit-2026-11-17.md),
[ecosystem research](research/ecosystem-research-2026-11-17.md),
[framework guide](research/framework-guide-2026-11-17.md),
[upstream ledger](upstream-integration-2026-11-17.md). Decisions and per-unit evidence are logged in
[program-trail.tsv](program-trail.tsv).

## Done means

The system is done when all of these hold:

1. Every unit below is source-complete.
2. `cargo check` passes for every touched crate. That covers the shared crates, the three adapters and
   UI crates, the launcher, and the examples on the Wasm target.
3. Focused unit tests of the shared crates pass.
4. Each unit has had an independent review whose findings are fixed or recorded.

Builds, app runs and CI wait for the owner's go-ahead.

## Phases

| Phase | Outcome |
|---|---|
| P0 Base | PhotoCraft upstream (framework UI) merged; `cargo check` baseline for every adapter |
| P1 Robustness | One bad plugin never takes down others or the app: per-plugin load, panic containment, helper death/restart, crash auto-disable, no UI-thread blocking |
| P2 Platform | Jobs (background, progress, cancel); host compute kernels callable from Wasm; hybrid packages (Wasm plus own native helper); opt-in restricted native mode |
| P3 Store | Catalogue 1.1 (category, tier, icon, description, screenshots, changelog, attestation); one cached, async manager model for apps and the launcher |
| P4 UI | Plugin Manager and store on the craft framework; plugin panels dock in every app; hosted windows and real OS windows; surface lifecycle events; launcher store section |
| P5 Projects | Missing plugins keep their data, show a cached result and a project dependency list with install-all; plugin project data and private settings |
| P6 SDK and DX | Typed bindings from the schemas, mock host for tests, `dev --watch`, plugin console, templates for every kind |
| P7 Flagships | Original example plugins in the class of the best-known After Effects and Photoshop plugins, used as acceptance tests |
| P8 Review | Cross-cutting review cycles, checks, docs |
