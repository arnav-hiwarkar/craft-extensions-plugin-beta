# Aspect coverage and acceptance evidence

> **Status (2026-11-10):** history and evidence. The current design is [the Craft plugin architecture](../architecture.md); where this document disagrees with it, the architecture wins.

Status: design coverage reference, 2026-11-08. This maps every row of [the aspect register](../aspect-register.md). ## Execution and application integration

| Register aspect | Normal path, adverse case and proposed default | Owner and detailed contract | Performance/compatibility consequence | Pending observable acceptance |
|---|---|---|---|---|
| Sandbox | Validate exact loaded bytes with real engine policy; deny undeclared imports/calls; no source-tier exception | App runtime with shared policy; [runtime boundaries](design.md#runtime-authority-and-budgets) | Parse/compile/stack/memory limits; engine profiles can differ; no proven native confinement on any OS | Import/feature rejection, malformed module, runtime trap and cancellation on each supported platform |
| Capability grants | Host-created identity invokes scoped operation; deny alternate wrapper and parameter escape | App host-call boundary plus authority snapshot; [command workflow](lifecycle.md#run-a-one-shot-command-or-interaction) | New rights block new release; check scope/generation per call; no generic command-bus access | Nested command, wrong document, hidden output path and mid-run revocation denial |
| Resource budgets | Allocate within per-job and total budgets; terminate boundedly on exhaustion | Runtime, scheduler and host brokers; [runtime budgets](design.md#runtime-authority-and-budgets) | Fuel does not bound blocking host work; logs/events/outputs/copies count too | Infinite loop, blocked host call, huge output/log storm, exhausted memory and concurrent-job limits |
| Documents and undo | Validate proposed edits and commit a transaction; discard trap/stale/cancelled work | Each app transaction engine; [commands](lifecycle.md#run-a-one-shot-command-or-interaction) | Revision checks; bounds on object count/event depth; durable handles over raw pointers | Undo/redo, stale handles, partial failure, reentrancy and cancelled long interaction |
| Persistent features | Save exact dependency and independent state; missing feature stays preserved; final export fails | App project format; [save/reopen](lifecycle.md#save-reopen-migrate-and-exchange-a-project) | Explicit upgrade/migration, state caps, baked fallback labelled; no executable auto-install on collaboration | Missing/revoked/incompatible/updated reopen, state round trip, failed migration and explicit bake |
| Media processing | Preserve app-purpose input/output semantics; reject wrong shape/context | EffectCraft/PhotoCraft/FilmCraft and other app adapters; [persistent evaluation](lifecycle.md#evaluate-a-persistent-effect) | Colour/alpha/precision/bands/overlap/time/units/temporal state explicit; no universal RGBA promise | Literal or tolerance-defined output fixtures, band/full-frame parity, temporal reset and geometry units |
| UI contributions | Native parameter forms and declarative callbacks invoke underlying operation; UI-only exception explicit | App UI/adapter; [adapter checklist](app-adapters.md#checklist-shared-by-every-adapter) | Localization/accessibility and callback disposal; trusted prompts remain host-owned | Same operation from panel/CLI, keyboard access, close/unsubscribe and unavailable headless panel |
| CLI and automation | Fresh/attached/server resolve same policy, explicit destinations, truthful completion | Each app session/job/artifact owner; [CLI sessions](lifecycle.md#use-cli-and-automation) | No orphan jobs or hidden dialogs; attached editor is authoritative; exit-code vocabulary open | Fresh eligible installed package, explicit output, InputRequired, cancellation and awaited artifact |
| GPU and native backends | Broker bounded host compute; fail visibly on device loss; defer arbitrary shaders/native backends | App compute broker; [backend decision](decisions.md#5-bound-the-first-capability-and-backend-scope) | Queue/transfer/memory costs and declared fallback; per-platform enforcement remains unproven | Future OS-specific confinement, device-loss/cancel and declared CPU fallback experiment |
| Audio | Preserve real-time DSP semantics through dedicated future contract; no generic runtime choice yet | SoundCraft audio owner; [audio row](app-adapters.md#concrete-integration-matrix) | Allocation/lock restrictions, deadlines, sample rate/layout, latency/tail/MIDI/state/editor lifecycle | Dedicated latency/dropout, transport, worker-failure, state and editor tests before runtime selection |
| Caches and scheduling | Reuse only identity/context-valid work; reset stateful instances; enforce fair total budget | App scheduler/runtime; [cache rules](design.md#themes-resources-and-authoring) | Keys bind digest/engine/contract/input/context; measure before pooling/copy optimization | Cache invalidation after parameter/time/colour change, instance isolation, cancellation and fairness measurements |
| Themes | Install data, preview/select deliberately, map supported tokens and fallback | Core ThemeFile, store reader, app mapping, craft-ui drawing; [theme rules](design.md#themes-resources-and-authoring) | Preserve app overrides/status/selection/contrast; no whole-app accessibility certification; ThemeCraft later | PhotoCraft and FilmCraft mapping/preview/cancel/fallback; later ThemeCraft round trip |
| Resources and workflows | Bounded typed import, resource readiness, separate explicit workflow execution | Resource client and existing importers; [resource rules](design.md#themes-resources-and-authoring) | Decoder/object/recursion limits; retained lazy data; fonts ownership; no install-time execution | Malformed LUT/brush/SVG/font/template, missing model/node, unsupported workflow; zero side effects on install |
| Diagnostics | Return precise structured reason and recovery, redact private data, support safe mode | Shared result vocabulary plus app support UI; [recovery](lifecycle.md#offline-use-incidents-and-safe-startup) | Bound log size; preserve unreadable state; release/app-scoped quarantine | Missing-dependency message in GUI/CLI, redacted support artifact and safe project startup |

## Delivery and ownership

Every app inherits all fourteen responsibilities in [the adapter checklist](app-adapters.md#checklist-shared-by-every-adapter). The matrix covers all sixteen sampled apps without claiming entry-point discovery establishes a plugin runtime. PhotoCraft's existing theme/filter work precedes the expanded EffectCraft-then-FigCraft functional proof as a complementary reuse slice, subject to the [proposed validation order](decisions.md#proposed-validation-order).

Clean dependency pinning, reproducible checkout, release-feature verification, platform coverage, legacy-ID migration, clean UI extraction, candidate packaging and independent security review remain future acceptance. The showcase branch is excluded from release. First-party completion does not satisfy the community gate by itself. No new installer, schema implementation, application code or CI changes belong to this research.

For uncertain decisions, [the deferred-scope table](decisions.md#deferred-scope-and-the-evidence-needed-to-reopen-it) identifies the smallest future experiment. This record deliberately does not assign arbitrary performance thresholds: app owners must set concrete budgets from representative workloads before runtime acceptance. No local Rust build/test or application benchmark is authorized or reported here.
