Open decisions
These are recommendations, not decisions. Decided so far: d0, d3, d5 and d7. r3 also needs one answer: whether the PhotoCraft panel is a Window menu dialog, a docked panel or a Preferences page.

Id	Question	Recommendation
d1	What does "extension" cover?	Three kinds: themes, plug-ins, resources (brush sets, LUTs, swatches, templates).
d2	User-facing name	Section "Extensions", tabs Themes, Plug-ins, Resources (PhotoCraft already says Plug-ins).
d4	Where the catalogue index lives	storytold/crafthub if the maintainers confirm it was meant for this (it is empty today, README says "Placeholder for merges"); otherwise a repo under Jeremy's account first.
d6	Does the launcher accept themes itself?	Optional. The default stays the look that matches getartcraft.com.
d8	Signing and metadata scheme for third-party gates	Ed25519 detached signatures, publisher keys pinned in the index, and TUF-style signed metadata (version, expiry, revocation). Look at adopting TUF's design before inventing our own.
d9	Provenance for third-party plug-ins	The hub builds plug-ins from source in its own CI and attests the build, rather than accepting uploaded binaries. Costly, strongest.
d10	Independent security review before the gate opens	Yes: an outside review of unpack, the sandbox host and the signature code, with findings fixed or accepted in writing.
d11	Where do plug-in download counts and rankings come from?	Start with download counts on storytold-hosted release files. They need no tracking inside the apps and no new server.
d12	What may a plug-in do, and how is each ability made safe?	A per-app ability list declared in the manifest and shown before install. Add each ability only once the sandbox can enforce it.
