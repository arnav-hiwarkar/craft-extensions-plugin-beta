Selected legacy ScriptUI workflow compared with the Craft beta. These are source findings and proposed follow-ups, without execution of community code.

Workspace panels

Legacy example

Dockable ScriptUI panel with palette fallback.

Beta now

Shared versioned UI. FigCraft docks panels; EffectCraft and PhotoCraft float them.

Next: host docking, saved layout and explicit lifecycle behavior.

Long-running work

Legacy example

Scheduled polling controls a local inference service.

Beta now

Bounded events and native supervision; no asynchronous app-job contract.

Next: progress/cancel jobs with fresh authorization when applying results.

Media and document edits

Legacy example

Source paths, generated sequences, effects and tracked masks.

Beta now

Scoped operation lists. PhotoCraft has picked files; EffectCraft lacks the required media/mask import workflow.

Next: chosen-media handles and canonical result import.

Permissions and OS access

Legacy example

App scripting preferences plus an independently installed service.

Beta now

Wasm uses declared/live rights and captured scope. Native has separately consented full OS access.

Preserve this boundary; add narrow services for concrete needs.

Authoring and migration

Legacy examples

BOUNCraft uses JSX and a Python writer for tiny control-effect Wasm modules. Anonymizer adds model/service setup.

Beta now

Rust SDK, templates, contracts, check/test/pack and multi-app contributions. The old and new ABI 1 protocols differ.

Next: a real port, missing-operation checklist and reproducible native setup.

Distribution and trust

Community evidence

The requested NZO store is inaccessible; its install/update checks remain unknown.

Beta now

Signed catalogue, archive digests, per-version native consent, pins and rollback.

Next: richer package evidence and setup diagnostics. Integrity is not sandboxing.

Animation authoring

BOUNCraft source

Selected properties, expressions, curve preview, numeric baking and grouped controls.

Beta now

Numeric property/key edits exist. Selected-property queries, expression editing and a deliberate control-group strategy are missing.

Next: scoped motion operations and a reference port, without arbitrary script dispatch.

Persistent preferences

BOUNCraft source

Custom presets use the app's legacy settings namespace.

Beta now

No private plugin-settings host API. Project references are a different kind of state.

Next: namespaced, quota-limited settings with schema and downgrade preservation.

Anonymizer is secondary evidence rather than the missing NZO store. BOUNCraft source and release bytes were inspected. Registry findings and exact revisions are in the comparison and backlog. No claim of complete application or GUI verification.
