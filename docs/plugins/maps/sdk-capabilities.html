A compiled host extends through explicit interfaces. These mechanisms have different access and failure boundaries.

Embedded scripting

Blender Python and EffectCraft ScriptUI call the app's exposed object model and build host UI.

Convenient authoring; API breadth and permission enforcement depend on the host.

Native library ABI

Compiled plugins receive callbacks and versioned host suites, as in native graphics SDKs.

Direct compute access; in-process code shares host privileges and crash risk. No generic beta DLL loader.

Sandboxed Wasm

Craft beta guests use bounded imports and explicit per-app operations with live authorization.

Only implemented host capabilities are available. Current beta filters have no temporal input contract.

Supervised native process

Craft beta helpers run separate executables; their host calls retain adapter authorization.

Full OS access after consent. A helper is not automatically a native render or GPU-buffer API.
